# Arqora Studio — product website

A responsive, static storefront and studio landing page using the existing TechForge project's soft neumorphic + glassmorphism visual language.

## Preview locally
Open `index.html` in a browser, or from this folder run:
```sh
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

## Included
- Responsive Arqora brand landing page
- Product catalogue cards for motion/video, design and web tools
- Working category filters and live product search
- Search overlay and mobile navigation
- Studio capabilities and contact form that prepares an email
- Keyboard skip link, visible focus states, accessible search dialog focus handling, and reduced-motion support
- Semantic sections, meta description and Open Graph basics
- Pure HTML/CSS/JS, no build tools or framework

## Before launch
- Replace concept/product statuses with actual availability and real product destinations.
- Set a real studio contact email in the contact form's mailto handler.
- Update domain, canonical URL and social metadata once the domain is known.
- Add privacy notice, analytics consent where required, and a real backend/payment flow only if selling directly from this site.
- Confirm all assets and product claims before publishing.

The page intentionally does not claim that products marked as concepts or in development are available for sale.
